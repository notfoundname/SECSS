# SECSS
This repository contains updated FGDs for different Counter-Strike: Source versions.

# Installation
Select specific FGD based on version you're mapping for.
Open Hammer++, Go to Tools -> Options -> Game Configurations -> Game Data files, remove everything and add downloaded file.

# Major Update
On February 18th 2025, Source SDK 2013 MP, as well as all official Valve games on that branch, received a major update.
You can read about it [here](https://www.teamfortress.com/post.php?id=238809).
I've desided to split FGD into two: `SECSS_2013.fgd` is for older 2021 update and `SECSS_2025.fgd` is for latest Steam version.

# Cautions
Loading it on an existing map might change different values of different entities, which may break some stuff! For now I can only suggest using it only for new maps.
